# Repository Agent Instructions

This repository is the WhatsApp Automation Platform.

Before significant work:

1. Load and follow the `whatsapp-platform-engineering` project skill located at `.agents/skills/whatsapp-platform-engineering/SKILL.md`.
2. Use `platform_docs/docs/INDEX.md` as the documentation map and authority guide.
3. Read `platform_docs/STATUS.md` before assuming what is implemented.
4. Work only on the requested epic or story unless an explicitly required prerequisite is missing.
5. Never invent files, APIs, schemas, commands, test results, provider capabilities, or existing behavior.
6. Treat `design-prototype/` as visual reference only, not production architecture.
7. Update `platform_docs/STATUS.md` and `platform_docs/CHANGELOG.md` when required by the project skill.
8. If normative documents conflict, follow the authority hierarchy defined by the project skill. Do not silently choose one.
